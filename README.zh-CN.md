# 美国通胀与宏观经济因素

本个人课程项目使用 Federal Reserve Economic Data 分析美国月度通胀动态。可复现流程将自回归通胀模型与货币、劳动力市场、能源价格和实际经济活动指标结合，并通过多种稳健性设定检验主要结论。

## 研究设计

- 因变量：CPI 同比通胀。
- 基准模型：AR(3) 时间序列回归。
- 协变量：货币条件、劳动力市场、货币供应量、WTI 油价增速和实际经济活动。
- 推断：12 阶 Newey-West HAC 标准误。
- 诊断：描述统计、相关分析、ADF、VIF、Durbin-Watson、Ljung-Box 和异方差检验。
- 稳健性：替代通胀指标、滞后阶数、样本范围、HAC 带宽、通胀变化模型及疫情前后子样本。

## 主要结果

| 指标 | 结果 |
|---|---:|
| 滞后构造后的分析区间 | 2001 年 4 月至 2026 年 5 月 |
| 基准样本量 | 298 |
| 选择的自回归阶数 | 3 |
| 调整后 R² | 0.953 |
| 三个滞后通胀系数之和 | 约 0.871 |

样本内通胀具有较强持续性。WTI 油价增速与 CPI 同比通胀呈稳定的条件正相关，货币供应量增速在不同设定中较不稳定，疫情后子样本的通胀截距更高。这些结果是观察性条件关联，不代表已识别的因果效应。

## 运行

```bash
python -m pip install -r requirements.txt
python run_all.py
```

命令会重建处理后数据、最终样本、来源审计、回归结果、诊断和稳健性表格。序列编号和来源记录在 `data/processed/data_source_audit.csv`。
